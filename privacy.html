Privacy Policy

Last updated: 5 November 2026

AuraFlow Publisher ("the tool") is a personal command-line application used by a single independent developer to publish videos to their own YouTube channel, AuraFlow AI. This policy explains what data the tool accesses and how it is handled.

YouTube API Services

The tool uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service, and data is handled by Google under the Google Privacy Policy.

Data the tool accesses

With the channel owner's OAuth 2.0 authorisation (scopes youtube.upload and youtube), the tool accesses only the authorised channel's own data: its basic channel details, its videos, thumbnails and playlists. It does not access data about other users or channels, and it does not use cookies or tracking.

How the data is used

The data is used only to upload the channel owner's videos, set their thumbnails and metadata, and organise them into playlists.

Storage

All data stays on the channel owner's own computer. The tool stores an OAuth refresh token and a local state file containing the IDs of the channel's own uploaded videos and playlists, so that nothing is uploaded twice. No data is sent to any server other than Google's.

Sharing

No data is shared with, sold to or disclosed to any third party.

Revoking access and deleting data

Access can be revoked at any time on the Google security settings page. Deleting the local token and state files removes all data the tool keeps. Stored API data is refreshed or deleted within 30 days.

Changes

Any changes to this policy will be published on this page with a new date.
